# 岗位匹配工作台 · Job Match Suite

> 导入简历，查找适合的岗位，查看匹配依据，打开投递链接。
> Windows 本地工具，可独立使用，也可与简历工作台配套；AI 精排可选。

## 这是什么

一个从简历出发的岗位筛选工具，帮助求职者减少反复搜索和逐条比对岗位要求的时间。

- **导入简历**：支持文字 PDF、Word（.docx）、TXT 和粘贴文字，解析后先核对求职信息
- **多平台搜索**：支持 BOSS 直聘、前程无忧、猎聘、智联等招聘来源，也可填写公司招聘官网
- **本地规则匹配**：根据目标岗位、城市、学历、工作年限、技能及薪资条件筛选，展示匹配依据与条件差距
- **可选 AI 精排**：对候选岗位分析匹配点、差距及待核对信息，不接 AI 也能正常搜索和使用规则匹配
- **岗位原文与链接**：可补充完整岗位要求，查看来源页面，打开原始详情或投递链接
- **导出清单**：将筛选结果导出为 TXT，便于后续跟进
- **简历工作台入口**：从配套工作台的「找匹配岗位」进入，使用当前简历的职业信息继续筛选

## 快速开始

### 从源码运行

需要已有的 Node.js 和 Electron 42.4.0，下面的 `electron` 命令需在终端中可用。仓库包含页面运行所需的 vendor 文件，不包含 Electron 安装包。

```powershell
git clone https://github.com/kk-6788/job-match-suite-public.git
cd job-match-suite-public

# 打开岗位匹配工作台
electron .

# 打开配套简历工作台
electron . --resume-workbench
```

已持有 Windows 便携版时，可直接打开 `job-match.exe` 或对应启动脚本；本仓库提供源码，不附带便携版下载。

**AI 功能可选**：在「AI 精排」中填写自己的服务地址、模型名和 API Key，支持兼容 Chat Completions 的服务。已有本地模型服务时也可使用回环地址。不开启 AI 时，本地规则匹配照常工作；招聘平台搜索需要联网。

## 支持的招聘来源

| 来源 | 使用说明 |
| --- | --- |
| BOSS 直聘、前程无忧、猎聘、智联招聘 | 搜索并读取当前页面岗位，按平台提示自行登录或验证 |
| 鱼泡直聘 | 支持任意岗位关键词；可在来源页面调整城市后继续读取 |
| 国聘 | 支持职位或单位关键词，读取当前列表前 10 个岗位链接 |
| 国家大学生就业服务平台 | 支持关键词搜索、当前页岗位读取和详情链接 |
| 实习僧 | 面向实习岗位；保留日薪单位，不与月薪直接比较 |
| 拉勾、应届生求职网 | 试读入口，可能要求登录或验证，登录后读取支持仍待完善 |
| 公司招聘官网 | 支持 JobPosting 结构化数据及可识别的职位详情链接；可填写最多三个招聘页 |

平台页面结构、登录状态和验证码可能影响读取。工具读取当前页面，不保证覆盖全站岗位或所有分页；可打开来源手动调整条件，再点击「继续读取」。

## 如何筛选和匹配

先核对简历中提取的目标岗位、城市、学历、工作年限、技能和最低月薪，再运行本地规则匹配。没有明确提供的信息保留为未知，由用户核对。

学历低于岗位要求一个层级、工作经验少不超过两年时，岗位仍会保留并提示差距；差距较大时默认隐藏，也可展开查看。日薪、时薪保留原单位，不直接与最低月薪比较。

开启 AI 后，先预览待发送内容，再确认发送。每次分析规则筛选后的前 10 个候选；调用失败时仍可使用规则结果。匹配分数是辅助判断，不是录用概率。

岗位卡片支持手动补充完整要求。当前不会自动批量抓取所有岗位的完整详情；只读到摘要时，应先补充原文再分析。AI 可能把未提供的信息误判为差距，最终需对照简历和岗位原文核对。

## 建议工作流程

1. 导入简历或粘贴文字，核对解析出的求职信息
2. 选择招聘来源，点击「查找匹配岗位」
3. 如需登录或验证，打开来源页面自行完成，再点击「继续读取」
4. 查看本地匹配结果，按需补充完整岗位要求
5. 可选开启 AI 精排，检查发送预览后运行分析
6. 核对岗位条件，点击「查看岗位 / 投递」，在平台上自行投递
7. 导出 TXT 岗位清单，记录后续跟进情况

工具不会自动投递，也不会替用户完成验证码。岗位是否仍在招聘、具体申请条件及流程，以来源平台为准。

## 与简历工作台配套使用

配套工作台中的「找匹配岗位」入口会传递当前稿的职业字段，不传姓名、联系方式、照片、原始全文或私人备注，也不修改原稿。

简历编辑、版式与导出工具可参考 [简历工作台 · Resume Studio](https://github.com/kk-6788/resume-builder-pro-public)。不同入口的数据和登录状态可能分别保存，切换使用前请自行备份需要保留的简历。

## 隐私与数据

- 简历解析和规则匹配在本机完成；搜索时向招聘平台提供岗位、城市等搜索词
- AI 精排会把预览中的职业信息和岗位文本发送给你配置的服务，云端调用可能收费；发送前请核对文本中的隐私信息
- 不内置 AI 密钥；手动设置与密钥仅保留当前窗口，不随源码分发
- 「使用本机 DeepSeek」由用户主动触发，读取现有 Hermes 配置或 `DEEPSEEK_API_KEY` 环境变量；密钥仅在主进程内存使用，不回传页面，只用于 DeepSeek 官方 HTTPS 接口
- 招聘平台登录状态保存在本机应用数据目录；岗位结果只留当前窗口，需要保留时请先导出
- 单文件上限 10 MB、文字上限 20 万字符；扫描 PDF 不支持 OCR

源码发布范围见 [PRIVACY.md](PRIVACY.md)。

## 开发与测试

测试依赖由 `resume-workbench/package-lock.json` 锁定。在项目根目录执行：

```powershell
Push-Location resume-workbench
npm ci
Pop-Location

$env:NODE_PATH = (Resolve-Path resume-workbench/node_modules).Path
node --test --test-isolation=none tests/*.test.cjs

Push-Location resume-workbench
node --test --test-isolation=none tests/*.test.cjs
Pop-Location
```

`job-matcher/` 包含岗位搜索、规则匹配和 AI 精排；`resume-workbench/` 包含配套简历编辑器；`desktop/` 提供桌面启动入口；`tests/` 包含岗位匹配工具的自动测试。
